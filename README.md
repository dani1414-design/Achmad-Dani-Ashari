🚀 Laporan Praktikum Machine Learning - Universitas PamulangRepositori ini berisi kumpulan tugas praktikum mata kuliah Machine Learning Program Studi Teknik Informatika, Fakultas Ilmu Komputer, Universitas Pamulang. Proyek ini mendemonstrasikan seluruh alur kerja (Machine Learning Pipeline) mulai dari pengumpulan data hingga evaluasi model klasifikasi.📂 Struktur Proyek & Tahapan PraktikumProyek ini dibagi menjadi beberapa tahapan utama sesuai dengan modul praktikum:Pertemuan 2: Data CollectingPengumpulan dataset berskala besar dari platform Kaggle (menggunakan Supermarket Large Dataset / Stroke Risk Prediction Dataset).Memahami sumber data, format tabular (CSV), serta relevansi atribut terhadap studi kasus bisnis dan kesehatan.Pertemuan 4: Data LoadingMemuat dataset eksternal berformat CSV ke dalam memori lingkungan pemrograman menggunakan bahasa Python.Pemanfaatan pustaka Pandas melalui fungsi pd.read_csv() di dalam Jupyter Notebook untuk mengonversi data mentah menjadi struktur objek DataFrame.Pertemuan 5: Exploratory Data Analysis (EDA)Menganalisis karakteristik struktural, tipe data, dan ukuran dimensi dataset (.info(), .head(), .describe()).Melakukan deteksi dini terhadap missing values, duplikasi data, serta visualisasi pola distribusi data dan korelasi antar-fitur menggunakan grafik Heatmap, Histogram, dan Box Plot (Matplotlib & Seaborn).Pertemuan 7: Data Preprocessing, Data Transformation, & Data SplittingPembersihan data dari kolom yang tidak relevan serta penanganan missing values dengan teknik imputasi statistik.Pembagian dataset (Data Splitting) menjadi data latih (training set) dan data uji (testing set) secara proporsional dengan parameter random_state dan stratify.Transformasi fitur melalui encoding (kategorikal ke numerik) dan feature scaling (standardisasi), yang diintegrasikan menggunakan Pipeline dan ColumnTransformer dari Scikit-Learn.Pertemuan 8: Modeling & Model EvaluationPelatihan model menggunakan berbagai algoritma klasifikasi (Logistic Regression, Random Forest, Hist Gradient Boosting, Decision Tree, Naive Bayes, dll).Evaluasi performa model menggunakan metrik komprehensif: Accuracy, Precision, Recall, F1-Score, ROC-AUC, serta visualisasi Confusion Matrix.🛠️ Teknologi & Pustaka yang DigunakanBahasa Pemrograman: Python   Lingkungan Kerja: Jupyter Notebook   Pustaka Utama:Pandas & NumPy (Manipulasi dan struktur data)   Matplotlib & Seaborn (Visualisasi data dan grafik analitik)   Scikit-Learn (Prapemrosesan, Pipeline, algoritma Machine Learning, dan metrik evaluasi)
